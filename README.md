# NeuroFit Timer — веб-версія

Веб-версія застосунку **The Project Hill / NeuroFit Timer**: трекер тренувань,
харчування та цілей із повноцінним таймером тренування.

Інтерфейс і палітра перенесені один-в-один з макета Flutter-прототипу
([`neuro_fit_timer`](https://github.com/DemchenkoAndriy/neuro_fit_timer)),
але статичний екран перетворено на робочий застосунок з даними, станом і фічами.

## Що вміє

**Головна**
- прогрес харчування і тренувань за програмою (`33/140`, `4/16`) зі шкалами;
- цілі (маса, об'єм біцепса) з відсотком і прогресом від старту до цілі;
- календар тижня: крапка — день тренування, галочка — виконано;
- картка сьогоднішнього (або наступного) тренування з переліком вправ і кнопкою «Старт».

**План**
- програма «Набір маси» — 4 тижні × 4 тренування (спліт: груди/трицепс, спина, біцепс, ноги/плечі);
- перемикання тижнів, стан кожного тренування, перехід у деталі.

**Тренування (деталі)**
- вправи з підходами, повтореннями, робочою вагою та часом відпочинку;
- результат попереднього проходження, якщо тренування вже виконане.

**Таймер тренування** — головна фіча
- машина станів `підготовка → розминка → підхід → відпочинок → заминка → підсумок`;
- **загальний годинник** у шапці рахує з першої секунди тренування (паузи не зараховуються);
- **час початку і завершення** фіксується за годинником і не залежить від пауз — видно
  на старті, у підсумку (`19:58 → 20:41`), в історії та в деталях тренування; поруч
  «чистий час», «від початку до кінця» і скільки простояли на паузі;
- **розминка на початку тренування**: без обмеження часу, таймер рахує вгору,
  завершується вручну;
- **заминка в кінці** — вимкнена за замовчуванням, вмикається на екрані підготовки
  окремо для кожного тренування;
- кільцевий індикатор: зворотний відлік «витікає», відкриті фази — накопичуються;
- фіксація кожного підходу: повторення + вага (крок 1 кг, підставляється з попереднього підходу);
- **час відпочинку редагується на старті** і застосовується до всіх вправ; під час
  відпочинку — `−15 с` / `+15 с`, пропуск, скасування підходу;
- **звук відліку — одна кнопка на три стани**: `Варіант 1` (сигнал за 10 с, 5 с і в кінці),
  `Варіант 2` (відлік вголос 10 → 0 через SpeechSynthesis, з фолбеком на біпи), `Без звуку`;
  тембр сигналів обирається в профілі (біп / дзвіночок / клац / гудок) з прослуховуванням;
- **віджет темпу 4/1** (налаштовується): вертикальна шкала збоку від кільця, щоб нічого
  не зсувати; анімується на `requestAnimationFrame` (60 кроків/с), метроном на кожну
  секунду опускання і тон на підйом, лічильник повторень;
- екран таймера **вміщається без скролу** — кільце і шрифти масштабуються під висоту
  екрана, для низьких екранів є компактний режим;
- пауза, вібрація, Wake Lock, щоб екран не гаснув;
- підсумок: загальний час, час під навантаженням, розминка, відпочинок, підходи,
  сумарний обсяг у кг;
- **деталізація в кінці тренування**: розминка і заминка окремими рядками, по кожній вправі — кожен підхід
  (повторення × вага), час під навантаженням і фактичний відпочинок після нього,
  плюс сумарний час на вправу;
- тренування зберігається в історію; незавершене тренування переживає перезавантаження сторінки.

**Челендж** — окремий режим таймера для підтягувань, віджимань, пресу
- ціль у повтореннях на сьогодні («50 підтягувань»), пресети або своя назва вправи;
- кількість повторень наперед не задається: робиш підхід і тиснеш «Підхід завершено»,
  а результат вписуєш уже під час відпочинку — крайній підхід редагується степером;
- відпочинок і завершення челенджу — вручну, без зворотних відліків;
- з часу під навантаженням автоматично віднімається 5 с на вхід і 5 с на вихід
  (підійти до турніка й зістрибнути), у залік іде тільки чистий час;
- кільце показує прогрес до цілі, лічильник — `24/50`;
- зберігається в ту саму історію, що й тренування, але не впливає на прогрес програми.

**Харчування**
- 5 прийомів їжі на день + вода (8 склянок), відмітки за будь-який день тижня;
- серія днів поспіль, загальний прогрес за програмою.

**Профіль**
- вага і зріст, редагування цілей;
- налаштування тренування (режим звуку, вібрація, автоперехід, wake lock, час підготовки);
- темп повторення: вмикання віджета і окремо секунди опускання/підйому;
- історія тренувань з обсягом, статистика, скидання прогресу.

Увесь стан зберігається в `localStorage` — дані живуть між сесіями.
На чистому старті застосунок засівається демо-історією (перший тиждень програми вже пройдено).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # продакшн-збірка в dist/
npm run preview  # перегляд зібраного
```

Потрібен Node.js 20+.

## Публікація

Репозиторій налаштований на GitHub Pages через Actions
(`.github/workflows/deploy.yml`): кожен пуш у гілку збирає `dist/` і публікує його.

Одноразове увімкнення: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Після цього сторінка живе за адресою
`https://demchenkoandriy.github.io/neuro_fit_timer_public/`.

Збірка використовує відносний `base: './'` і hash-роутинг, тому працює з підкаталогу
без додаткових налаштувань — і так само на Vercel, Netlify чи будь-якій статиці
(команда збірки `npm run build`, каталог `dist`).

## Стек

- **React 19 + TypeScript + Vite** — швидкий dev-цикл, статична збірка без бекенду;
- **React Router** (hash-роутинг) — деплой на будь-який статичний хостинг, включно з GitHub Pages;
- **CSS-змінні** замість UI-бібліотеки — токени в `src/styles/tokens.css` відповідають палітрі макета;
- без зовнішніх залежностей для іконок, стану чи анімацій.

## Структура

```
src/
├─ components/   UI-примітиви (кільце таймера, степер, календар тижня, навігація…)
├─ data/         програма тренувань і константи харчування
├─ hooks/        таймер-тік, звук, вібрація, wake lock, машина станів тренування
├─ screens/      Головна, План, Тренування, Таймер, Харчування, Профіль
├─ state/        типи стану, reducer, персистентність, селектори
├─ styles/       токени, глобальні стилі, стилі екранів і таймера
└─ utils/        робота з датами й форматування часу
```

Ключові файли:
- `src/hooks/useWorkoutRunner.ts` — машина станів тренування;
- `src/state/selectors.ts` — уся похідна аналітика (прогрес, серії, обсяг);
- `src/data/program.ts` — програма; змінюється без правок UI.

## Далі: мобільний додаток

Верстка mobile-first (колонка 480 px, safe-area, PWA-маніфест), тому наступний крок —
обгортка Capacitor: `npx cap init` → `npx cap add ios/android`, і той самий код працює
як нативний застосунок. Логіка тренування (`hooks/`, `state/`) не залежить від DOM,
тож переносна і на React Native, якщо знадобиться повністю нативний UI.
